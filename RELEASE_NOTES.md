# GAMMA Alternative Stash Progression v2.1.0

The standalone addon adds ordinary and yellow stashes from dead stalkers in every GAMMA game mode, including Story Mode and Warfare. Corpse searches are an alternative when access to task givers is limited.

Corpse stashes preserve GAMMA's task counter and reward index. Yellow stashes from both sources share the native toolkit unlocks. GAMMA picks loot by stash location and current unlocks, and a generated repair toolkit unlocks its tier when the cache is created.

English and Russian MCM menus offer four presets, automatic Custom, adjustable stash chances, optional zombified stalkers and Debug Mode. Very Fast defaults to 16% / 16%. Debug Mode and zombified stalkers are off by default.

## Compatibility

Developed and tested for **S.T.A.L.K.E.R. GAMMA 0.9.5** with Rare Stashes Balance and Anomaly MCM. Other versions are unverified. The adapter declines requests with an unsupported manager or wrapper. GAMMA's own corpse-stash listener remains active.

## Install or upgrade

Disable the superseded **Warfare Alternative Stash Progression** and any earlier copies in the active MO2 profile. Install `GAMMA_Alternative_Stash_Progression_v2.1.0_MO2.zip` as a new mod, enable it and restart the game. Saved corpse IDs carry forward and legacy preferences fill missing settings. Progress already spent or unlocked by older builds stays as saved.
